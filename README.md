## Identitas Peserta

## Deskripsi Repository
Repository ini dibuat sebagai dokumentasi kegiatan workshop *Building with AI, Managing Change with GitHub* yang disampaikan oleh Nugi Farhan.

Repository ini berisi rangkuman materi, catatan pembelajaran, serta pengetahuan baru mengenai prompt engineering, Git, GitHub, dan penerapan version control dalam pengembangan proyek.

## Tujuan Repository
1. Mendokumentasikan materi yang dipelajari selama workshop.
2. Memahami penggunaan AI untuk membantu pengembangan aplikasi.
3. Memahami perbedaan Git dan GitHub.
4. Mempelajari pengelolaan perubahan file menggunakan Git.
5. Mempraktikkan penggunaan repository GitHub.
