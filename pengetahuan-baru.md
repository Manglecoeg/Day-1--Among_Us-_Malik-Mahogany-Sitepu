# Pengetahuan Baru dari Workshop

Berdasarkan materi workshop, beberapa hal penting yang dipelajari adalah sebagai berikut.

### 1. Pentingnya konteks dalam prompt AI
Prompt yang rinci membantu AI memahami tujuan, persyaratan, dan bentuk keluaran yang diharapkan. Oleh karena itu, penyusunan prompt perlu memperhatikan role, task, context, dan format.

### 2. Git dan GitHub memiliki fungsi berbeda
Git digunakan untuk mengelola riwayat perubahan proyek, sedangkan GitHub menyediakan layanan penyimpanan repository secara online serta fasilitas kolaborasi.

### 3. Commit membantu mendokumentasikan perkembangan proyek
Setiap commit merekam perubahan pada suatu tahap pengembangan. Pesan commit yang jelas membantu pengguna memahami perubahan yang telah dilakukan.

### 4. Staging area merupakan bagian penting dari Git
Sebelum melakukan commit, pengguna dapat menentukan perubahan mana yang akan dimasukkan melalui staging area.

### 5. Repository dapat digunakan sebagai dokumentasi pembelajaran
GitHub tidak hanya digunakan untuk menyimpan kode program, tetapi juga dapat menjadi tempat menyusun README, catatan, dan dokumentasi proyek.

### 6. AI dapat membantu pengembangan aplikasi sederhana
Melalui prompt yang terstruktur, AI dapat membantu menghasilkan rancangan dan kode awal aplikasi seperti Student Task Planner. Namun, hasilnya tetap perlu diperiksa dan diuji.

### 7. Version control mendukung pengembangan berkelanjutan
Setiap perubahan proyek dapat direkam secara bertahap sehingga riwayat pengembangan lebih mudah ditelusuri.

## Refleksi
Materi workshop memberikan pemahaman mengenai hubungan antara AI, pengembangan aplikasi, dan version control. Penggunaan Git dan GitHub membantu mengelola perubahan proyek secara lebih sistematis, sedangkan prompt engineering membantu merumuskan instruksi yang lebih jelas ketika menggunakan AI.
